\section{Project Timeline}

\subsection{Project Check-In Day 1}

By project check-in day 1, the following milestones should ideally be completed:
\begin{itemize}[noitemsep, topsep=0pt]
    \item The game environment should be established and built within the Robotarium platform.
    \item The real-time strategy game interface should be designed and partially implemented
    \item The LLM interface should be designed and partially implemented
\end{itemize}

\subsection{Project Mid-Point "Poster" Session}

By the project mid-point poster session, the following milestones should ideally be completed (in addition to the milestones above):
\begin{itemize}[noitemsep, topsep=0pt]
    \item The real-time strategy game interface should be fully implemented and functional
    \item The LLM interface should be fully implemented and functional
    \item The user study should be designed and ready to be conducted
    \item The mid-point poster should be completed and presented
\end{itemize}

\subsection{Project Check-In Day 2}

By project check-in day 2, the following milestones should ideally be completed (in addition to the milestones above):
\begin{itemize}[noitemsep, topsep=0pt]
    \item The user study should be conducted and completed
\end{itemize}

\subsection{Final Project Presentations}

By the Final project presentation, the following milestones should ideally be completed (in addition to all other milestones above):
\begin{itemize}[noitemsep, topsep=0pt]
    \item The user study should be analyzed and the results should be presented
    \item The final project poster should be completed and presented
\end{itemize}
