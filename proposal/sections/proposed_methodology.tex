\section{Proposed Methodology}

The main goal of our project is to create a real-time strategy game interface and an LLM interface for controlling a MAS in a game environment.  We will then perform a \textbf{within-subjects} user study to evaluate the performance and user experience of the two interfaces (\textbf{counterbalanced} against the interface selection).  Specifically, we will be evaluating the performance of the MAS in terms of the score achieved in the game and the user experience of the participants in terms of task load and usability.  To measure task load, we will be using the \textbf{NASA Task Load Index (NASA-TLX)} \cite{hart_development_1988}.  To measure usability, we will be using the \textbf{System Usability Scale (SUS)} \cite{brooke_susa_1996}.  Additionally, we will be collecting qualitative feedback from the participants to gain insight into their experience with the two interfaces.

The first major part of our project is creating a game environment for the MAS to operate in.  We will be using the Robotarium \cite{pickem_robotarium_2017} as our MAS platform and will be creating a game environment for the MAS to operate within.  Our main goals for the game environment are to create a game that is challenging enough to require coordination of a large number of agents and that includes a both positive and negative rewards.  Specifically, much of the previous work has focused on contrived examples that do not require conforming to a set of constraints, whereas these are incredibly important aspects of real-world MAS problems.  Therefore, our game environment will include a set of negative feedback constraints that must be communicated to the MAS by the human operator.  Additionally, we will be creating a scoring system for the game that will provide positive feedback to the MAS for completing tasks and negative feedback for failing to complete tasks or violating constraints.

With the Robotarium providing a software simulator, hardware, and runtime environment for the MAS, we will be able to focus on creating the game environment and interfaces for controlling the MAS.  The team has not yet decided on the specific LLM for use in the project, but selecting the LLM will be one of the first tasks for the project.  Additionally, we will be creating a traditional real-time strategy game interface for controlling the MAS.  A technology stack has also not yet been selected for the real-time strategy game interface, but the design is meant to adhere to the human-computer interaction principles for real-time strategy games as presented in \cite{wenjun_hci_2006} and \cite{riaz_user_2021}.
