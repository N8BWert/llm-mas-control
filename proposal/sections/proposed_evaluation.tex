\section{Proposed Evaluation}

The project is considered successful if the following criteria are met:
\begin{itemize}[noitemsep, topsep=0pt]
    \item A game environment is created utilizing the Robotarium platform
    \item A real-time strategy game interface is created for controlling the MAS
    \item An LLM interface is created for controlling the MAS
    \item A user study is conducted to evaluate the performance and user experience of the two interfaces
\end{itemize}
